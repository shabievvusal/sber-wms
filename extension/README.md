# СберЛогистика в WMS — расширение браузера

Разделы robops.ru прямо внутри WMS (wwh.samokat.ru), без переключения между сайтами.

## Установка (Chrome / Edge / Яндекс Браузер)

1. Открыть страницу расширений: `chrome://extensions` (Edge — `edge://extensions`, Яндекс — `browser://extensions`).
2. Включить **«Режим разработчика»**.
3. **«Загрузить распакованное расширение»** → выбрать эту папку `extension`.
4. Открыть или обновить wwh.samokat.ru — в боковом меню WMS после «Отчёты» появится пункт **«СберЛогистика»** с разделами сайта.

После правок в папке — на странице расширений нажать «обновить» (круговая стрелка) у расширения и перезагрузить WMS.

## Как работает

- В меню WMS после «Отчёты» — сворачиваемый пункт «СберЛогистика» со всеми разделами сайта. Раздел открывается справа от меню WMS, на месте рабочей области; подсвечивается так же, как родные пункты. Клик по любому пункту WMS или «← WMS» возвращает в WMS, раздел при этом не перезагружается.
- Меню WMS находится по самим пунктам («Мониторинг», «Отгрузка», «Отчёты»), а не по классам — переживает обновления вёрстки WMS. Если меню не нашлось (сильно поменялось), слева внизу появляется запасная кнопка «СберЛогистика».
- Первый раз внутри WMS нужно войти на сайт (телефон и пароль, как на robops.ru) — вход запоминается отдельно для WMS на 30 дней.
- WMS-токен из открытой сессии WMS передаётся сайту автоматически — разделам, которые ходят в WMS (Поставки, Списки ЕО…), не нужен отдельный вход в WMS. Передаётся только access-токен; его обновляет сама WMS.

## Что нужно на сервере robops.ru

Пересобрать `dotnet` и `node` (фронтенд): вход из встроенного окна ставит cookie `SameSite=None; Secure; Partitioned` — иначе браузер не пустит сессию во встроенное окно. Обычный вход на robops.ru не меняется.

## Тёмная тема WMS

В дизайн-системе WMS тёмная тема уже есть (класс `.default-dark-theme`, переопределяет все `--color-…`), сама WMS её просто не включает. `theme.js` (запускается на `document_start`, без белой вспышки) ставит этот класс на `<html>`. Переключатель — пункт «Тема: …» в группе «СберЛогистика» меню WMS и кнопка в полосе окна раздела: светлая → тёмная → как в системе. Выбор хранится в localStorage WMS (`zlp-wms-theme`), встроенный сайт получает тему сообщением `zlp:theme`.
